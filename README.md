# MyanTone Connect

Build a polished, modern, production-ready web application called:

MYANTONE AI

Tagline:

“Say it in Myanmar. Send it naturally in English.”

Product positioning:

MyanTone AI is a Myanmar-first AI communication assistant that helps Myanmar users translate what they mean into natural English and create professional English messages and emails.

The product should NOT feel like a basic translation website.

It should feel like a premium AI communication assistant that understands:

1. What the user means

2. Who they are communicating with

3. The communication situation

4. The desired tone

5. Whether the user wants a sentence, message, or complete email

2. MAIN PRODUCT CONCEPT

==================================================

MyanTone AI has two primary capabilities:

A. TRANSLATE

Myanmar → Natural English

B. EMAIL STUDIO

Myanmar intention → Complete English email

The system should understand meaning rather than perform literal word-for-word translation.

Example:

Myanmar:

“ဒီနေ့ meeting မတက်နိုင်ဘူးလို့ အလုပ်ကလူကို ပြောချင်တယ်”

Possible outputs:

Simple:

“I can't attend today's meeting.”

Polite:

“I'm sorry, but I won't be able to attend today's meeting.”

Professional:

“I apologize, but I will be unable to attend today's meeting.”

Formal:

“I regret to inform you that I will be unable to attend today's meeting.”

Friendly:

“Hey, I won't be able to make it to today's meeting. Sorry about that!”

## Running locally (GitHub clone)

The Myanmar → English quality comes from the Lovable AI Gateway. On Lovable the
`LOVABLE_API_KEY` is injected automatically; a local clone has no key, so the app
falls back to a small offline rule engine and every result looks generic
("I wanted to let you know about this."). An amber notice in the UI tells you
when that is happening.

To get real AI results locally:

```bash
cp .env.example .env      # then paste your LOVABLE_API_KEY into .env
bun install
bun run dev
```

Vite loads `.env` automatically and the key is only ever read inside server
functions — it is never sent to the browser. `.env` is gitignored; never commit it.
